# UniShop — сайт-витрина для аграриев

Многостраничный сайт (SPA) без сборки: откройте `index.html` в браузере.

## Структура
```
index.html              разметка всех страниц, шапка, подвал, всплывающие окна
css/style.css           собственные стили (эффекты, карусель, анимации)
js/tailwind-config.js   цвета и шрифты Tailwind
js/app.js               данные каталога, меню, фильтры, сравнение, формы
images/                 фотографии (см. images/README.txt)
download_images.py/.sh  скачивание фото в images/
```

## Фото
1. Выполните `python download_images.py` (или `sh download_images.sh`) — 8 фото сохранятся в `images/`.
2. Пока папка пуста, сайт сам берёт те же фото с Unsplash.
3. Свои фото: положите файлы с теми же именами или поменяйте пути в блоке `IMG` в начале `js/app.js`.

## Что менять
- Товары и фильтры: массив `products` и объект `CAT` в `js/app.js`.
- Контакты, тексты, адрес: `index.html`.
- Отправка форм: блок «ФОРМЫ» в `js/app.js`.
- Карта в подвале: `src` у `iframe` в `index.html`.

## Важно
Tailwind и шрифты подключены по CDN, нужен интернет. Для полностью офлайн-сайта соберите Tailwind и скачайте шрифты.
